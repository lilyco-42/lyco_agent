lyco — 本地 Agent（小白版）

像用 codex / claude code 一样，但模型与记忆全部在你自己机器上： 不需要 API token，也不需要先懂 python / node / uv。

① 推荐方式：下载一个 zip，解压，双击 lytray.exe —— 完事

下载 lyco-windows.zip（约 4.5 MB）

右键「全部解压」→ 打开解压出的文件夹 → 双击 lytray.exe。 屏幕右下角出现 lyco 托盘图标，右键它：

  • 一键机房自举（Python 环境） —— 点一下，装 uv + 配镜像 + 建 PyQt6 工程，全自动
  • 打开包目录 / 打开终端 / 退出

没有任何命令行，没有 python，没有 node，没有安装过程。

② 命令行党：PowerShell 一行流 
powershell -ExecutionPolicy ByPass -c "irm https://lain42.top/lyco-dl/bootstrap.ps1 | iex"
下载 lycore.exe 并写入用户 PATH，展开记忆包，自动冒烟。
③ 单独下载
  • lycore.exe —— CLI 本体（Rust 单文件，零运行时依赖）
  • packs.zip —— mpkg 记忆包合集

mpkg 记忆包：每个包有唯一 content-id，可验证、可离线回放 —— 「装环境」这类重复劳动固化成一个包，一条命令（或托盘点一下）跑完，退出码说话。
