# 数据「信息量 vs 重复量」2×2 对照（2026-09-19）

**问题**：弱线索语义泛化（heldB）卡在 ~80%，瓶颈到底是**参数量**还是**数据**？
（v7b 已用显著结果否掉参数量：0.6B→1.7B 在 heldB 上 p=0.0078 更差。）

**设计（唯一自变量 = 每个能力的「唯一说法数」）**
- **训练样本量固定**（1300 / 2600），只变"有多少种不同的说法" → 才能区分**信息量**与**重复量**
- 2×2：`信息(低/高) × 体积(1×/2×)`，四臂同模型/同超参/同解码/同环境
- 新说法由强模型（教师）生成；**只造有线索说法**，并断言与留出模板重叠 = 0（保护 heldB 的有效性）
- 留出评测集固定（heldA 227 / heldB 116），跨臂完全一致 → 配对 McNemar

**结果**

| 臂 | N | 唯一说法 | heldA | heldB |
|---|---|---|---|---|
| A1 信息LO·体积1× | 1300 | 426 | 203/227 = 89.4% | **112/116 = 96.6%** |
| A2 信息HI·体积1× | 1300 | 616 | 213/227 = 93.8% | 99/116 = 85.3% |
| A3 信息LO·体积2× | 2600 | 655 | 202/227 = 89.0% | 97/116 = 83.6% |
| A4 信息HI·体积2× | 2600 | 1015 | **223/227 = 98.2%** | 107/116 = 92.2% |

| 对比 | heldA | heldB |
|---|---|---|
| 信息量效应（A2 vs A1，同体积） | 14:4 **p=0.0309 显著↑** | 1:14 **p=0.0010 显著↓** |
| 纯体积效应（A3 vs A1，同信息） | 4:5 p=1.0000 不显著 | 1:16 **p=0.0003 显著↓** |
| 双高 vs 双低（A4 vs A1） | 24:4 **p=0.0002 显著↑** | 1:6 p=0.1250 不显著 |

## 结论

1. **heldA（自然换说）由「信息量」驱动，重复量无效**（体积效应 p=1.0）。
   与 DeepSeek-V4.1-Flash 报告"过滤 implicit duplication"、RobustTool-SLM"Random Augmentation
   在 Robust 上只有 65.8%"同向。双高配置最好：heldA 98.2%。
2. **heldB（弱线索）反向：加信息、加量都显著变差**。机理来自失败分桶 ——
   `invalid_syntax` 在弱线索输入上从 **2 → 9~10**：训练数据越多，模型越**依赖关键词**；
   而 heldB 的题面刻意**缺少关键词**。因此 **A1（数据最少）反而是 heldB 最好的一臂**。
3. **行动结论**：
   - 提升"自然换说"→ 扩**不同说法**（真实中文指令数据值得投），**不要靠堆重复**；
   - 提升"弱线索"→ 必须**定向**把弱线索/口语说法纳入训练（即 RobustTool-SLM 的 Recovery 数据路线），
     或重新审视 heldB 的定义（其中不少题是"单关键词可推断"，可能并不代表真实语义泛化）。
4. **变量披露**：本实验训练池 = `T_TRAIN + T_EXTRA + noop`，**未含 T_FAIL**；
   与 v7b 的训练池不同，故 **v7b / v7c 不可跨 run 比较**，有效结论仅限于 v7c 内部 2×2。
