# 人代替 AI：语料采集操作说明（2026-09-24）

> 目的：**让人坐 AI 的位子**。人看候选、人选编号、人填参数、执行、落盘。
> 人做的每一次，就是一条**真值语料**——NL 是真人说的、命令是人确认的、`exit_code` 是真实执行结果。
>
> 为什么需要它：我们训了 5 次全负，根因之一从来没变过——**从来没有自己的真数据**。
> 用过的数据要么是别人的通用对话（moss-003/COIG-CQIA，跟 CLI 无关），
> 要么是我们自己合成的"想象"（datagen，从来没被执行过）。

## 1. 一条命令

```bash
lycore do "<人话>" --cli <cli> [--dry-run] [--pick N] [--record <file>]
```

| 参数 | 作用 |
|---|---|
| `--cli` | 指定 CLI（不写就从人话里猜） |
| `--dry-run` | 只出计划不执行（**先看清楚再动手**） |
| `--pick N` | 非交互指定编号（脚本/批量用，日常不用） |
| `--record` | 落盘路径，默认 `~/.lbrush/YYYY-MM-DD.ndjson` |
| `--top N` | 候选展示条数，默认 40 |

## 2. 一次完整的采集

```text
$ lycore do "看看提交日志" --cli git

[CLI] git（help 2290 字符 → 24 条动作，展示 8 条）
[人话] 看看提交日志

【git 候选动作】（只回编号；一个都不合适就回 0）
1. git status
2. git log
...
0. 以上都不合适（不执行）

选哪个? 2                      ← 人做判定（这一步将来换成模型）
[命令] git log
[风险] read（只读查询类, 可直接执行）
[决策] run
[退出码] 0
[已记录] ~/.lbrush/2026-09-24.ndjson
```

## 3. 落盘的一条长这样

```json
{"ts":1790180942,"nl":"看看提交日志","cli":"git","idx":2,"action":"git log",
 "cmd":"git log","slots":[],"risk":"read","decision":"run",
 "exit_code":0,"executed":true,"judge":"human"}
```

| 字段 | 含义 |
|---|---|
| `nl` | 人话（**真人说的**） |
| `idx` | 人选的编号，**0 = 都不合适** |
| `cmd` | 最终命令 |
| `slots` | 人填的槽位值 |
| `risk` / `decision` | T1 门的分诊结果（read/write/danger + run/confirm/block/reject） |
| `exit_code` | **真实退出码**——我们所有旧数据里从来没有的信号 |
| `judge` | 现在恒为 `human`；将来接模型后改 `model` |

## 4. 采集纪律（决定这批数据值不值钱）

### ✅ 值得采

- **你真正会说的话**——口语、省略、含糊都行（"看看提交"、"提交记录给我看下"）
- **同义说法多采几条**——同一条命令配 3~5 种问法，比 5 条不同命令更值钱
- **出域请求一定要采**（选 0）：`"帮我订张机票"` / `"给我讲个笑话"`。
  这是**拒绝的正样本**——我们 reject 一直是 0%，之前根本没有途径拿到。
- **写操作也采**（`git commit`、`npm install`）：让模型学会"哪些要确认"

### ❌ 不要采

- 你自己都说不清该选哪个的（选错了会训进噪声）
- 候选里**没有**你想要的命令时，不要将就选一个近似的——**选 0**
- 用 `--dry-run` 跑的（不执行就没有 `exit_code`，只能算"意图样本"不是"执行样本"）

### 🔴 一条硬规矩

**选错了不要回头改记录。** 数据里的错误 Selection 也是有价值的（说明候选排布有问题），
改掉就失去了排障线索。真想重采，**追加一条新的**，不要修改旧的——文件是 append-only 的。

## 5. 现在的可用范围

| CLI | 状态 |
|---|---|
| `git` / `docker` / `npm` / `cargo` | ✅ 可直接采（2 级子命令，不受截断缺陷影响） |
| `hw`（Radxa 板子） | ⏳ 等 `parse_help` 修复验证通过后再采（3 级子命令：`hw led blue off`） |

## 6. 采完之后

数据可以直接当：
1. **训练语料**（`nl` → `cmd`）
2. **评测集**（真实人话 + 真值命令）
3. **拒绝能力样本**（`idx == 0` 的那批）
4. **Failure Ledger 的输入**（`exit_code != 0` 的那批，用来归因是哪一层坏了）
